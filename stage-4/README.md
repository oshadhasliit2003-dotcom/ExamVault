# EV-04: The Lecturer's Laptop (Player brief)

A lab computer used by a lecturer account was imaged. Work out when the exam paper was copied and which USB device was used.

**Your task:** analyse the evidence in `evidence.tar.gz`.
**Flag format:** `EXAM{usbserial_HHMM}`: the serial number of the USB device that held the copy, and the UTC time (24-hour, no colon) the exam paper was copied.
Distributed as a file download in CTFd.
